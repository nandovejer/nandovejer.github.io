2024

“Mejorar el HTML nativo en lugar de sustituirlo.”

Descripción

Un sistema de diseño ligero, usable y sin dependencias. Tokens de CSS por capas, componentes y JavaScript vanilla que mejoran el HTML nativo en lugar de sustituirlo. Todo funciona sin JavaScript, y es la base sobre la que están construidos casi todos los proyectos que vienen después.
