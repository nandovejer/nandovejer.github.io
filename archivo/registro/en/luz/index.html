“Enhance native HTML instead of replacing it.”

Description

A light, usable and zero-dependency design system. Layered CSS tokens, components and vanilla JavaScript that enhance native HTML instead of replacing it. Everything works without JavaScript, and it is the foundation almost every project that follows is built on.
