Fernando Muñoz

Est. MMXXVI

Memoirs of a coder who writes

Frontend Tech Lead · Madrid

I am Fernando Muñoz, though almost everyone calls me Nando. I work as a Frontend Tech Lead in Madrid and spend my days between Adobe Experience Manager and Salesforce Commerce Cloud, two giants I am paid to bring order to.

I believe in HTML that works without JavaScript, in CSS that reads like a book and in zero-dependency tools that will still stand ten years from now. So I build lightweight design systems, demos that respect your privacy and the odd tribute to the Cádiz Carnival.

I code and I write. Sometimes it is hard to tell one from the other.

Chapter I

LUZ

Design system

A light, usable and zero-dependency design system. Layered CSS tokens, components and vanilla JavaScript that enhance native HTML instead of replacing it. Everything works without JavaScript, and it is the foundation almost every project that follows is built on.

Enhance native HTML instead of replacing it.

2024
Language
JavaScript
  1. Online edition nandovejer.github.io/luz
  2. Source code github.com/nandovejer/luz

Chapter II

IKAY

Browser fingerprint

A tool to see, identify and manage your browser fingerprint. It shows a dashboard of 33 data points you hand over to any website without being asked for a single permission, and explains in plain language what each one means for you. AA contrast, AAA in high contrast, and three languages: Spanish, English and Arabic.

Thirty-three data points, zero permissions.

Year
2026
Language
JavaScript
  1. Online edition nandovejer.github.io/ikay-vanilla
  2. Source code github.com/nandovejer/ikay-vanilla

Chapter III

Chrome Local AI

AI in the browser

Demos of the artificial intelligence APIs built into Chrome with Gemini Nano: summarise, translate, proofread, chat or generate data that follows a JSON Schema. Everything happens on your device: there is no server and, once the model is downloaded, no connection is needed either. Bilingual, built with Astro, TypeScript and LUZ.

Artificial intelligence that never leaves your computer.

Year
2025
Language
TypeScript
  1. Online edition nandovejer.github.io/apiChrome
  2. Source code github.com/nandovejer/apiChrome

Chapter IV

¿Quién canta hoy?

Cádiz Carnival

The schedule of the Official Carnival Groups Contest at the Gran Teatro Falla, session by session: which groups sing today and in what order. No backend, built with LUZ and designed to be checked on your phone on the way to the theatre.

Which groups sing today, and in what order.

2023
Language
TypeScript
  1. Online edition nandovejer.github.io/coac-quien-canta-hoy

Chapter V

Ares API

Music archive

A static, zero-dependency API for the complete discography and works of Antonio Martínez Ares. Nothing but JSON files served from GitHub Pages: no database, no server and no build step, with open CORS so anyone can query it.

A whole body of work in JSON files.

2026
Language
JavaScript
  1. Online edition nandovejer.github.io/api-coac
  2. Source code github.com/nandovejer/api-coac

Chapter VI

Toolbar AEM

Chrome extension

A floating toolbar for Adobe Experience Manager pages that lets you jump between the Editor, Sites, CRXDE and every environment without retyping URLs. Bookmarks, a coloured favicon per environment and settings you can share with your team. Plain JavaScript, Manifest V3, no build step and no dependencies.

Jump between consoles without retyping URLs.

Year
2025
Language
JavaScript
  1. Source code github.com/nandovejer/toolbar-aem

Chapter VII

Acme Studio

Accessibility

A website that looks clean but is broken on purpose: invisible focus, images without alternative text, links that do not look like links. A test bench for practising accessibility audits by finding the errors one by one.

Broken on purpose, so you can learn to fix it.

Year
2026
Language
HTML
  1. Online edition nandovejer.github.io/accessibility
  2. Source code github.com/nandovejer/accessibility

Chapter VIII

Libros del mundo

Library

A literary journey across the continents: one book per country, with a single rule, that it was published in 2010 or later. A window onto the cultural soul of each place, told by authors who live and feel their own land, with links to the world's libraries that hold it.

One book per country, published since 2010.
